# NEXUS-VPN 1.0 — Инструкция для Пользователей

## Что это?
Программа для Windows, которая позволяет подключаться к твоему серверу VPS  и выходить в интернет с минимальным пингом (8–12 мс).

## Скачай приложение
- Скачай `nexus-vpn.exe` из папки `target/release` (или запусти из исходников).

## Как установить и использовать
1. Установи приложение (один клик).
2. В меню или главном окне:
   - Введи IP сервера VPS
   - Введи SSH-логин и пароль
   - Нажми «Подключить к серверу»
3. Программа автоматически:
   - Определит ОС сервера
   - Установит твой сервер (TUN + NAT + forwarding)
   - Включит туннель
4. Включи/выключи соединение кнопкой «Подключить / Разорвать»
5. Для раздельного туннелирования:
   - Открой список программ
   - Выбери приложения (Chrome, Telegram и т.д.)
   - Для них трафик будет идти напрямую

## Как отключить
- Нажми «Разорвать соединение» или выйди из приложения.

## Преимущества
- Полностью новый протокол NEXUS-VPN
- Всё на твоём сервере VPS
- Работает даже если в Болгарии блокируют обычные VPN
